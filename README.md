# Machine Learning 2026–2027

Coursework and practical notebooks for the Machine Learning course at Selçuk University.

This repository contains the assignments completed throughout the 2026–2027 academic year. Each assignment is stored in a separate numbered folder together with its notebook and related notes.

## Assignments

### 01 — Titanic Data Preprocessing

Basic data preprocessing on the Titanic dataset using Pandas and NumPy.

Topics covered:
- Data inspection and data types
- Numerical and categorical feature identification
- Missing value handling
- Z-score standardization
- Min-Max normalization
- Label Encoding
- One-Hot Encoding
- Data visualization

Notebook:  
`01_titanic_veri_on_isleme/01_titanic_veri_on_isleme.ipynb`
