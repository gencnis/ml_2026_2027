# Machine Learning 2026–2027

Coursework and practical notebooks for the Machine Learning course at Selçuk University.

This repository contains the assignments completed throughout the 2026–2027 academic year. Each assignment is kept in a separate numbered folder together with its notebook, data, reports, and related files.

## Assignments

### 01 — Titanic Data Preprocessing

Basic data preprocessing on the Titanic dataset using Pandas and NumPy.

Topics covered:
- Data inspection and data types
- Missing value handling
- Z-score standardization
- Min-Max normalization
- Label Encoding
- One-Hot Encoding
- Data visualization

Folder: `01_titanic_veri_on_isleme/`

---

### 02 — Regression and Gradient Descent

Linear regression and Gradient Descent practice in two parts.

The first part applies Min-Max normalization and two Gradient Descent iterations manually on a small housing-price dataset.

The second part builds a simple linear regression model using head circumference to predict brain weight. The dataset is split into training and test sets, and the model is evaluated using R², MSE, and MAE.

Topics covered:
- Min-Max normalization
- Gradient Descent
- Linear regression
- Train/test split
- R², MSE and MAE
- Regression visualization

Folder: `02_regresyon_gradient_descent/`
