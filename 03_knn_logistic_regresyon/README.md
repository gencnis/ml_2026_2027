# 03 - KNN and Logistic Regression

This assignment covers two classification exercises.

The first part applies K-Nearest Neighbors manually to classify a target point using Euclidean distance with `k = 3`.

The second part uses the diabetes dataset to train a Logistic Regression model. The dataset is split into training and test sets, standardized using `StandardScaler`, and evaluated with common classification metrics.

The final model achieved approximately 71% accuracy and a ROC-AUC score of 0.823.
