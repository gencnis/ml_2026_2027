# 04 - Decision Tree and Naive Bayes

This assignment covers Decision Tree and Naive Bayes classification.

The first part involves calculating entropy and information gain manually to determine the first split of a decision tree.

The second part uses Gaussian Naive Bayes to classify the breast cancer dataset. The model was trained using 30 numerical features with an 80/20 train-test split.

The model achieved 93.86% accuracy and a ROC-AUC score of 0.9934.
